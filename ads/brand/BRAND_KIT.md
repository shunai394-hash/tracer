# TRACER ブランド統一キット（Shopify・BASE 向け）

TRACER本体（tracer-pied-alpha.vercel.app）と同じ見た目に、Shopify・BASEをそろえるための設定値。
どちらも管理画面での手作業になる。この環境からは、ShopifyのテーマAPI・BASEのデザイン設定に接続できないため。
BASEのAPIは商品と注文だけを扱い、デザイン設定のAPIはない。
購入機能や配送設定には触れず、見た目の設定だけを変える。

## 1. 色
| 用途 | 色コード |
|---|---|
| 背景（アイボリー） | `#FBF6F1` |
| サブ背景（ブラッシュピンク） | `#F6E2E0` |
| 文字・ボタン（ココア） | `#3B241A` |
| 本文・補足（ブラウン） | `#5C4035` |
| 見出し上の英字ラベル | `#9A6B5B` |
| 強調・残りわずか（ローズ） | `#B84A62` |
| 枠線 | `#EADBD3` |

## 2. 文字
- 見出し・ロゴ：明朝体（Shopifyなら「Noto Serif JP」や「Shippori Mincho」、BASEなら明朝系のフォント）
- ロゴの表記：`TRACER`（字間を広めに）
- 本文：ゴシック体（初期設定のままでよい）

## 4. 文言（3サイト共通）
- キャッチコピー：**毎日を、少しだけ上品に。**
- サブコピー：バッグ、ヘアアクセサリー、メイク小物。いつもの装いに寄り添うアイテムを集めました。
- ボタン：すべての商品を見る ／ バッグを見る
- お知らせバー：価格はすべて税込表示 ／ 配送・返品条件は各商品ページでご確認いただけます
- ストーリー：いつもの毎日に、小さなときめきを。
- 「送料無料」「返品保証」など、各サイトで確認できていない約束は書かない。

## 5. Shopify での手順（テーマエディタ）
1. Shopify管理画面の「オンラインストア → テーマ → カスタマイズ」を開く。本番テーマを直接変えず、まずテーマを「複製」して、複製した方で作業する。
2. テーマ設定の「色」で、背景 `#FBF6F1`、文字とボタン `#3B241A`、サブ背景 `#F6E2E0` を設定する。
3. 「タイポグラフィ」で、見出しに明朝系のフォントを選ぶ。
4. トップページの先頭に「画像バナー」セクションを置き、3章のPC用画像を設定する。見出しと文言は4章のとおりにする。
5. その下に「コレクションリスト」（バッグ・ヘアアクセサリー・メイク小物）と「おすすめ商品」を置く。
6. 「お知らせバー」に4章の文言を入れる。
7. プレビューで確認してから、複製したテーマを「公開」する。

## 6. BASE での手順（デザイン設定）
1. BASE管理画面の「デザイン」から、シンプルなテーマ（白・余白が多いもの）を選ぶ。
2. 背景色を `#FBF6F1`、文字色を `#3B241A` に設定する（テーマで色を変えられる場合）。
3. ショップロゴは文字の `TRACER`（明朝系）か、同じ表記のロゴ画像にする。
4. メインビジュアル（トップ画像）に、3章のPC用画像を設定する。
5. ショップの説明文に、4章のキャッチコピーとサブコピーを入れる。

## 7. 商品データの統一（見た目より売上に効く）
- 商品名と商品画像は、TRACERの連携機能（Shopify・BASEへの公開の定期処理）で同期されている。名前や画像を直すときは、各管理画面ではなくTRACER側のデータを直す。各管理画面で直すと、次の同期で元に戻る可能性がある。
- 直すべきデータ：BEAUTY FORMULAの画像URLが404になっている／色違いの商品に同じ写真が使われている／「眉メイク用 ショルダーバッグ」のような不自然な商品名。
