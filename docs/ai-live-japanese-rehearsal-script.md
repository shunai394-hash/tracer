# AIライブ販売リハーサル台本（日本語・ローカル検証用）

> **ローカル検証専用。** ここに出てくる商品は架空のデモ商品です。実在商品・実在在庫・配送予定・購入可能性を示しません。実配信や外部音声APIへの接続は行いません。

## 進行ルール

- 商品データにない性能、素材、サイズ、配送日、保証、割引を作らない。
- 在庫・価格・購入先は、最新の承認済みフィードが確認できない場合は断定しない。
- 注文変更、返金、苦情、健康・安全に関する質問はAIだけで判断せず、担当者へ引き継ぐ。
- 「AIによる案内」であることを視聴者に明示する。
- 同じ説明を繰り返す場合は言い回しを変え、購入を過度に急かさない。

## 30〜60分のテスト構成

1. **0〜3分：開始・開示** — AI販売員であること、今日は動作確認用のデモであることを説明。
2. **3〜10分：商品紹介** — 商品名、登録済み説明、価格の順で読み上げる。未登録情報は補わない。
3. **10〜20分：コメント応答** — 価格、商品説明、在庫、購入先、配送、返品・苦情のテスト質問を順番に試す。
4. **20〜30分：反復・割り込み** — 同じ質問、曖昧な質問、回答できない質問で安全な応答を確認。
5. **30分時点：判定** — 重大な誤回答がゼロなら、担当者の判断で最大60分まで延長。
6. **終了時：停止確認** — 読み上げとアバター動作を停止し、未回答・引き継ぎ対象を記録する。

## コメント応答テンプレート

| 質問カテゴリ | 応答テンプレート | 判定 |
|---|---|---|
| 価格 | 「デモ画面に表示されている価格は2,980円です。これは架空データで、実商品の価格ではありません。」 | 表示値のみ使用 |
| 商品説明 | 「登録済みの説明をお伝えします。これは動作確認用の架空商品です。」 | 未記載の特徴を追加しない |
| 在庫 | 「このデモでは在庫ありの例を表示しています。実商品の在庫状況は確認していません。」 | 実在庫と混同しない |
| 購入先 | 「これはデモのため、購入可能な商品ではありません。実際の販売時は確認済みの商品ページをご案内します。」 | 購入可能と誤認させない |
| 配送日 | 「配送予定はこのデモでは確認できません。確認済みの配送情報がある場合にのみご案内します。」 | 日付を推測しない |
| 返品・返金・苦情 | 「正確な確認が必要なため、担当者に引き継ぎます。」 | 自動で約束しない |
| 不明・曖昧 | 「その点は確認できていません。推測でお答えせず、担当者に確認します。」 | 断定しない |

## 記録する指標

- 質問数、回答できた数、担当者への引き継ぎ数
- 事実にない情報の追加（目標：0件）
- 価格・在庫・配送に関する誤回答（目標：0件）
- 読み上げ遅延、音声認識失敗、停止操作の確認
- 実配信・実注文・外部API呼び出しが発生していないこと

## 次段階へ進む条件

- 全テスト質問で誤認を招く回答がない。
- 不明な情報を推測せず、担当者へ引き継げる。
- 停止操作が機能し、30分テストの記録が残る。
- 実商品を使う場合は、承認済みの商品フィードの読み取り検証が成功している。

この文書は台本・評価基準のみであり、実配信、音声合成、コメント取得、注文処理は実装しません。
