「手持ち素材」は自分の動画・画像を編集します。「Pexels無料素材」はキーワードに合う既存のストック映像を集めて編集します。どちらも文章から新しいAI映像クリップを生成する機能ではありません。

動画の内容

台本は音声・字幕の元になります。複数人物の演技や口パクを自動生成する機能は含みません。

選んだ順番で編集します。動画はMP4 / MOV / AVI / MKV / WEBM、画像はJPG / PNG / BMP / WEBP。

1行に1シーン、またはカンマ区切りで入力。映像検索は英語キーワードの方が見つけやすい場合があります。台本の展開順に並べてください。

制作時の注意

ナレーションのEdge TTSはAPIキー不要ですが、音声合成時にはインターネット接続が必要です。完全オフラインではありません。PC負荷を抑えるため同時制作は1本、FFmpegは1スレッド。SNSへの自動投稿は行いません。

Pexels APIは無料プランでも利用回数制限があります。保存済みの既存APIキーを使ってください。新規キー発行が停止中の場合は、手持ち素材モードを利用してください。
